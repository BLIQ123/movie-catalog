# Movie Catalog Service

Полнофункциональный веб-сервис каталога фильмов с REST API на FastAPI, реляционной базой данных SQLite/PostgreSQL и клиентской частью. Проект предоставляет интерфейс для просмотра каталога, поиска, фильтрации, а также управления коллекцией фильмов и постеров к ним.

---

## 1. Описание проекта

**Movie Catalog** — это веб-приложение, предназначенное для каталогизации и структурированного хранения информации о фильмах. Бэкенд реализован в виде RESTful API с автоматической генерацией интерактивной документации Swagger/OpenAPI. Проект поддерживает миграции схемы данных через Alembic, валидацию входных данных посредством схем Pydantic и хранение медиафайлов (постеров).

---

## 2. Основные возможности

* **Каталог фильмов:** получение списка фильмов с поддержкой пагинации, сортировки и детальной информации по каждому тайтлу.
* **CRUD-операции:** создание, чтение, обновление и удаление записей о фильмах через REST API.
* **Медиа-хранилище:** загрузка, статическая раздача и хранение постеров фильмов.
* **Управление базой данных:** применение и откат миграций схемы с помощью Alembic, наличие скриптов сброса (`reset_db.py`) и начального наполнения данными (`seed.py`).
* **Интерактивная документация:** встроенный Swagger UI (`/docs`) и ReDoc (`/redoc`) для удобного тестирования эндпоинтов.

---

## 3. Стек технологий

* **Язык программирования:** Python 3.10+
* **Фреймворк:** FastAPI
* **ASGI-сервер:** Uvicorn
* **ORM и работа с БД:** SQLAlchemy, SQLite (по умолчанию) / PostgreSQL
* **Миграции БД:** Alembic
* **Сериализация и валидация:** Pydantic
* **Frontend:** HTML5, CSS3, JavaScript

##6. Как запустить проект
Предварительные требования
Установленный Python 3.10 или новее.

Утилита Git.

Шаг 1. Клонирование репозитория
git clone [https://github.com/ваш-логин/movie-catalog.git](https://github.com/ваш-логин/movie-catalog.git)
cd movie-catalog
Шаг 2. Настройка виртуального окружения
Windows (PowerShell):
python -m venv .venv
.venv\Scripts\Activate.ps1
Шаг 3. Установка зависимостей
cd backend
pip install -r requirements.txt
Шаг 4. Подготовка базы данных
Примените миграции и при необходимости заполните базу тестовыми данными:
alembic upgrade head
python seed.py
Шаг 5. Запуск сервера бэкенда
Находясь в директории backend, выполните:
uvicorn app.main:app --reload
Шаг 6. Запуск фронтенда
Откройте второй терминал, 
перейдите в директорию fronted и откройте файл index.html в браузере 
(напрямую либо с помощью расширения Live Server / любого локального HTTP-сервера).
